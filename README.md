# homebrew-tap

Homebrew formulas for 8th Light tools.

## repo-tutor

Teaches a code repository as a fast onboarding course in your terminal.

```sh
brew install 8thlight/tap/repo-tutor
```

The formula is generated and committed by the release workflow of [8thlight/repo-tutor](https://github.com/8thlight/repo-tutor). Do not edit `Formula/` by hand.
